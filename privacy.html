Privacy policy

Last updated 17 October 2026.

Channel Agents is a private publishing tool used only by its owner to upload, schedule and measure videos on the owner's own YouTube channels, Instagram account and Facebook Page.

Data we access

With the owner's permission the tool uses the YouTube Data API, the YouTube Analytics API and the Meta Graph API to upload videos, set their titles, descriptions, thumbnails and playlists, and read view and engagement statistics of the owner's own channels and pages.

How data is used and stored

Data is used only to publish the owner's videos and to decide what to publish next. Statistics are stored in the owner's private GitHub repository. Access tokens are stored as encrypted GitHub Actions secrets. No data is sold, shared with third parties or used for advertising.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions and in Facebook settings under Business integrations.
